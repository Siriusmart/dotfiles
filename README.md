## Apps with theme
- `btop`
- `hyprland`
- `hyprlock`
- `obs-studio` (with `pipewire-pulse` as dep)
- `kitty`
- `zsh` (requires `ttf-jetbrains-mono-nerd`, `zoxide` and `fzf`)

- `rofi-wayland`, `rofi-calc`

- `bc`
- `fzf`
- `noto-fonts`
- `mpv`
- `qt5-wayland`, `qt6ct`
